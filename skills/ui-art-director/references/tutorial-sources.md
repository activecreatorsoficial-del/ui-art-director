# Reviewed tutorial sources

These user-supplied tutorials informed version 0.2.0. Review used their public captions, chapter metadata, selected frames, and short temporal frame sequences. This was not continuous full-video playback or a measurement of exact easing curves. The dashboard reference was sampled at the supplied 00:54 point as well as later relevant sections.

## UI reference analysis

[The stupid simple way to learn UI/UX design in exactly 10 minutes](https://www.youtube.com/watch?v=9WVt1CelBfg), Kole Jain.

Relevant sections: 00:34-02:33, 03:21-04:32, and 05:15-07:36. The tutorial separates layout structure, visual treatment, and user journeys. Reviewed examples show grouping through spacing, protecting an image's focal area, and changes in visual emphasis. Our adaptation uses contextual analysis and original implementation rather than adopting the example's exact pixel values or a fixed learning schedule.

## Dashboard organisation

[EVERYTHING you need to know to build a Dashboard UI in 8 minutes](https://www.youtube.com/watch?v=B7k5rOgmOGY&t=54s), Kole Jain.

Relevant sections: 00:54-01:32, 01:54-04:08, 04:40-05:52, and 07:24-08:03. Reviewed material connects navigation, working-area density, data presentation, and contextual interaction. Our adaptation adds input accessibility and recovery requirements, and treats optimistic updates as existing application behaviour requiring failure handling. The demonstrated grid and surface treatments remain examples rather than universal rules.

## Presentation motion

[The Ultimate Apple Style Animation Guide](https://www.youtube.com/watch?v=5j4HmfgPCDI), NaughtyyJuan.

Relevant sections: 02:24-03:13, 03:13-04:12, and 04:26-05:18. The implementation shown is primarily After Effects. Captions and sampled sequences demonstrate eased movement, visual continuity, word reveals, and surface treatments. Our original browser example adapts general movement concepts to interactive states, cancellation, and reduced motion. It does not reproduce the tutorial's paid pack, exact font requirement, or promotional claims.
